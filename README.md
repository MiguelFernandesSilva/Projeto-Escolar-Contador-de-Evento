# Documentação Técnica: Contador de Evento

## Visão Geral do Projeto
O projeto **Contador de Evento** é uma aplicação web interativa desenvolvida com foco em layout responsivo e componentes reutilizáveis para exibição de eventos, captura de dados do usuário e contagem regressiva em tempo real.

---

## Tecnologias Utilizadas
- **HTML5:** Estruturação semântica de todo o conteúdo da página, formulários e elementos da interface.
- **CSS3:** Estilização visual, regras de responsividade e layout dinâmico dos componentes.
- **JavaScript:** Lógica interativa para cálculo e exibição da contagem regressiva em tempo real.

---

## Abilidades Reforçadas
- **Clean Code**: O código foi estruturado de forma organizada e dívidido em blocos simples para rápido entendimento de terceiros.
- **Autonomia**: Diversas pesquisas sobre métodos e comandos foram feitas através de análises de documentações, gerando autonomia de aprendizado
- **Gestão de Adições**: O trabalho geral foi dividido em etapas simples, para que seu desenvolvimento se tornasse mais fácil e organizado.

---

## Componentes Gerais do Projeto

| Componente | Descrição Resumida |
| :--- | :--- |
| **Barra de Navegação (Navbar)** | Cabeçalho fixo no topo contendo o logotipo do projeto e links de navegação rápida para as seções da página. |
| **Banner Principal** | Seção de destaque inicial com título do evento, breve introdução e o contador regressivo em destaque. |
| **Contador Regressivo** | Bloco dinâmico que exibe a contagem de tempo (dias, horas, minutos e segundos) até a data especificada. |
| **Cards de Eventos / Informações** | Blocos organizados em grade (grid) que detalham atrações, horários ou informações gerais sobre o evento. |
| **Formulário de Contato** | Área com campos de texto para nome, e-mail e mensagem, destinada ao suporte e envio de dúvidas. |
| **Formulário de Compras / Inscrição** | Seção interativa com campos estruturados para seleção de ingressos/opções e dados do comprador. |
| **Tabelas Informativas** | Estruturas de dados tabulares para exibição clara de cronogramas, preços ou programação do evento. |
| **Rodapé (Footer)** | Seção final da página contendo direitos autorais, links para redes sociais e informações institucionais. |
| **Responsividade** | Código feito de forma pensada para funcionar em diversos aparelhos, sendo automáticamente responsívo a diferentes aplicações. |
